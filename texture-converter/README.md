# Texture Converter

이 프로젝트는 PySide6를 사용하여 텍스처 변환을 위한 GUI 애플리케이션입니다. 사용자는 높이 맵을 선택하고 이를 노멀 맵으로 변환할 수 있습니다.

## 설치

이 프로젝트를 실행하려면 다음 요구 사항을 설치해야 합니다:

```bash
pip install -r requirements.txt
```

## 사용법

1. `main.py`를 실행하여 애플리케이션을 시작합니다.
2. GUI에서 높이 맵 이미지를 선택합니다.
3. 변환 버튼을 클릭하여 노멀 맵을 생성합니다.
4. 생성된 노멀 맵을 저장합니다.

## 테스트

테스트는 `tests` 디렉토리 내의 파일에서 수행됩니다. 단위 테스트를 실행하려면 다음 명령어를 사용하세요:

```bash
pytest
```
